# Scoring rubric (0–4 per pillar)

Score each pillar with evidence from the page. When in doubt between two scores, pick the lower one and say what would raise it.

## Effort

| Score | Description |
|---|---|
| 0 | Auto-generated or copied with no visible human work. Could be produced from a feed or a prompt in seconds. |
| 1 | Template or AI draft with light edits. Generic structure, no first-hand inputs. |
| 2 | Clear human work (organisation, editing, some research) but no first-hand data, media or tooling. |
| 3 | Substantial work: original research, custom media, real examples, or a working tool. |
| 4 | Exceptional work hard to replicate: tests, datasets, long-term tracking, expert interviews, custom systems. |

## Originality

| Score | Description |
|---|---|
| 0 | Copied, scraped or a paraphrase of top results. |
| 1 | Same facts and angle as the top results, reworded. |
| 2 | Mostly known information with a few unique details or a different structure. |
| 3 | Clear unique contribution: own data, own cases, own photos, a new angle. |
| 4 | The original source others would cite. |

## Talent or skill

| Score | Description |
|---|---|
| 0 | Hard to read or use, broken elements, misleading layout. |
| 1 | Readable but padded, poorly structured, or missing what the purpose needs. |
| 2 | Competent and clear. Meets the purpose without standing out. |
| 3 | Well crafted: answers fast, strong structure, good media, shows real expertise where needed. |
| 4 | Best-in-class execution for its purpose. |

## Accuracy

| Score | Description |
|---|---|
| 0 | Contains clear factual errors or harmful advice. |
| 1 | Unverified claims, outdated facts, or likely AI hallucinations. |
| 2 | Generally correct, few sources, some vague claims. |
| 3 | Correct, specific and sourced where it matters. |
| 4 | Precise, current, sourced, and aligned with expert consensus (required for YMYL). |

For YMYL pages, any accuracy score under 3 caps the overall verdict at "At risk".

## Overall verdict

Sum the four scores (0–16), then check the commodity class and red flags. When they point to different tiers, take the lowest tier.

- **13–16, non-commodity, no red flags**: Strong.
- **9–12, or partly commodity**: Solid with gaps.
- **5–8, or commodity**: At risk in a core update.
- **0–4, or any Lowest red flag**: High risk. Improve, consolidate or remove.

The score is a heuristic to prioritise work. It is not Google's score.
